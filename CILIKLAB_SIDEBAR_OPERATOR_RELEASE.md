# CilikLab — grouped sidebars, Operator Demo and RoboLab judges' unlock

1. Student and Teacher sidebars keep every existing destination individually clickable, organized under visual section headings.
2. Operator View is available directly from the **Student / Teacher / Operator** switcher in the top header. Mobile profile dropdown includes all three roles. No login or credentials.
3. Operator has a grouped sidebar and uses fictional demo records saved locally in the browser; records do not affect real accounts. Read `OPERATOR_DEMO_README.md`.
4. RoboLab has all 8 worlds and 40 missions unlocked for judging. Normal progression tracking continues and can be restored by changing one boolean in `src/pages/arcade/robolab/demoConfig.ts`.
5. Prior features—Daily Coding Challenge with Python/C/Java, Heyzine flipbooks, 3D RoboLab gameplay and classroom UI—remain in the project.
